# Web App

TanStack-first frontend for Urban Heat Democratization.

## Stack

- TanStack Router
- TanStack Query
- TanStack Form
- TanStack Table
- Vite + React + TypeScript

## Local development

```bash
npm install
npm run dev
```

## Notes

- This shell currently uses a local mock API so the user flows are interactive without a backend.
- The Python backend will replace the mock layer in the next phases.
