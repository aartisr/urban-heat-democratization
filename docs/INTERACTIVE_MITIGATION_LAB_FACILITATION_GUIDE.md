# Interactive Heat-Mitigation Lab: 15-minute facilitation guide

1. State the question: “Where might a combination of shade and surface changes
   deserve closer investigation?” Emphasize that the lab is not a forecast.
2. Start with the fictional grid. The high heat-pressure node is a prompt to
   investigate, not a claim about people or a location. Pick an intervention
   from the compact grid picker, place it, read the modeled priority shift,
   and name one local fact the model does not know.
3. Compare a second sketch. Ask participants to explain the difference using
   the evidence and applicability drawer—not a temperature claim.
4. Optionally open the Boston study aggregate. Explain that it is a coarse
   aggregate of bundled study context, not an address-level map or a local
   cooling estimate.
5. End by recording the next validation step: observation, ownership check,
   maintenance discussion, access verification, or a community conversation.

When a cooling-access node is placed, explain that the displayed graph metrics
are computed by the same canonical evaluator as the production pipeline and
Robustness Lab. The bounded redundant-link learning scenario is not an
infrastructure recommendation or a demonstrated outcome.

Use “modeled,” “planning hypothesis,” and “needs local review.” Do not say
“will cool,” “proves,” or “guarantees.”
