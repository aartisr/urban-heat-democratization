# Verified Cost Sources

This repository intentionally avoids inventing mitigation costs.

## Real sources added

1. `Cool Communities Program, Los Angeles (1997)`
   - A city-scale cooling package cited in urban heat literature at about **US$1 billion**.
   - In this repo it is used as a coarse benchmark for whole-city mitigation planning.
   - It is not treated as a fake per-tree or per-roof unit price.

2. `Mitigating New York City's Heat Island With Urban Forestry, Living Roofs, and Light Surfaces`
   - A NYSERDA report cited in the literature for relative cost effectiveness.
   - The key takeaway is ranking: light surfaces, light roofs, and curbside planting are cheaper per temperature reduction than street trees.
   - This source is used for prioritization only, not as a full unit-cost table.

3. Public seed-cost examples were added for a small number of related interventions.
   - Light surfaces now have a seed cost row anchored to public concrete staining guidance as a proxy for reflective hardscape treatments.
   - Street trees now have a seed cost row drawn from a public program-cost example.
   - Curbside planting now shares the same public tree-cost anchor as a second verified forestry row.
   - Shade structures now have a seed cost row based on public reporting about playground shade project costs.
   - Transit shade canopies now reuse the same public shade-structure anchor as a verified canopy seed row.
   - Cool roofs now have a seed cost row derived from a public roof-cost anchor.
   - Green roofs now have a seed cost row derived from a public case-study example.
   - Permeable paving now has a seed cost row derived from a public driveway-cost guide.
   - Cool pavement now has a seed cost row derived from a public report on a NYC pilot program and quoted sealant premium.

## Why the app still stays cautious

The repository now has real cost references, but not yet a city-specific procurement table. That means the app can show verified benchmark sources and a few seed unit-cost examples, while still refusing to pretend that Boston has exact tree, roof, and pavement prices unless those numbers are added from a public source.
