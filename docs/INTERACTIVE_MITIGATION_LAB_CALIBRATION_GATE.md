# Interactive Heat-Mitigation Lab Calibration Gate

Calibrated local-study output is disabled in the application. A completed UI,
an intervention placement, or an observed post-project change cannot unlock it.

Before activation, the study owner must provide and independently review:

1. A registered outcome, geometry, timing, inclusion rules, comparisons, and
   analysis plan.
2. Comparable baseline and follow-up observations, including weather, sensor,
   missing-data, and matched-scene rules.
3. A documented counterfactual with pre-trend, spillover, placebo, uncertainty,
   and robustness diagnostics.
4. Data retention/governance approval, partner approval, and public-language
   review.

This checklist implements the release gates in the
[Impact Evidence Protocol](IMPACT_EVIDENCE_PROTOCOL.md). Only an approved,
registered study may add a calibrated result path; it must remain separate from
the browser planning model.
