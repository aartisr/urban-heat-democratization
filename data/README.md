This folder stores bundled study inputs and planner evidence files.

Key files:

- `intervention_catalog.json`
  Base intervention catalog with ranking-only and benchmark-only evidence.
- `intervention_unit_costs.json`
  Dedicated verified unit-cost overrides merged into the base intervention catalog at API load time.
- `cost_sources.json`
  Source-backed benchmark and comparative planning references.

Place small demo rasters here too when needed, for example:

- `demo_lst.tif`
- `demo_ndvi.tif`
